Dossier triage contracts

OpenAPI 3.1.0 · versão 1.0.0

Isto é documentação de contrato. A aplicação não está publicada, e isso é decisão, não pendência de tempo.

O sistema falha fechado sem verificação de JWT/JWKS (pendência P-1): fora de NODE_ENV=development nenhuma principal verificada é emitida, em nenhuma chamada. Publicar a aplicação exigiria desligar essa guarda num sistema que decifra CPF. Um contrato estático não tem banco atrás e não decifra nada — por isso ele pode ser publicado e a aplicação não.

Este arquivo é gerado a partir dos mesmos schemas Zod que o servidor valida em runtime. Contrato escrito à mão em paralelo ao código é proibido neste projeto: se o código muda o contrato, a diferença aparece aqui.

Operações

POST /api/v1/carteiras/{walletId}/dossies/lookup

Compõe o dossiê do título indicado. O identificador é o id externo do título; não existe consulta por pessoa.

Parâmetros

  • walletId em path — obrigatório

Corpo da requisição — application/json

{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "properties": {
    "id_externo": {
      "type": "string",
      "minLength": 1
    }
  },
  "required": [
    "id_externo"
  ],
  "additionalProperties": false
}

Respostas

200 Dossiê composto e classificado.

application/json

{
  "type": "object",
  "properties": {
    "classification": {
      "$ref": "#/components/schemas/Classification"
    }
  }
}

403 Sem capacidade sobre a carteira.

404 Título ausente desta carteira. Indistinguível de título inexistente, de propósito.

GET /api/v1/carteiras/{walletId}/prioridades

Lista a carteira por prioridade operacional, paginada por cursor opaco.

Parâmetros

  • walletId em path — obrigatório
  • cursor em query — opcional
  • limit em query — opcional

Respostas

200 Uma página, mais o cursor da próxima.

400 Cursor inválido. O cursor é opaco e não deve ser construído pelo chamador.

GET /api/v1/dossies/{dossierId}/prompt

Projeção do dossiê para consumo por agente, versionada e determinística.

Parâmetros

  • dossierId em path — obrigatório
  • carteira em query — obrigatório

Respostas

200 Texto do prompt.

text/markdown

{
  "type": "string"
}

404 Dossiê fora do alcance desta carteira.

Toda requisição exige o cabeçalho Authorization e responde cache-control: no-store: o dossiê é dado pessoal de pessoa identificada. Não existe consulta aberta por CPF — o único identificador que o chamador segura é o id_externo do título, dentro de uma carteira que ele já tem autorização para ler.

A pontuação ordena esforço de cobrança entre devedores. Ela não estima se alguém vai pagar, e não deve ser apresentada nem usada como se estimasse.
